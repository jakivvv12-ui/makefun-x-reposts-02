Entry for make.fun's "Get the most reposts and likes on make.fun's newest X posts" bounty. The program writes the kit post list to the output directory; the placeholder X post URL is replaced after the human posts from @BasedMolang.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
